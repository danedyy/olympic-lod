# Olympic LOD

Permanent identifiers for the Olympic LOD project: the Tokyo 2020 Olympic Games as 5-star Linked Open Data,
by Daniel Samuel Edim and Ahmad Imran (Faculty of Engineering, University of Porto).

* Ontology: `https://w3id.org/olympic-lod/ontology#…`
* SHACL shapes: `https://w3id.org/olympic-lod/shapes#…`
* Code lists: `https://w3id.org/olympic-lod/scheme/{list}/{value}`
* Data: `https://w3id.org/olympic-lod/tokyo2020/id/{type}/{key}`

Project: https://github.com/danedyy/olympic-lod
